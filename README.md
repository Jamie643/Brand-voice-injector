# Brand Voice & Tone Style-Transfer Engine

A reusable system prompt that rewrites dry, technical, or messy notes into a
consistent brand voice.

## What this is

Role prompting + few-shot examples + negative constraints, assembled into one
prompt template. Tested across three content types: email, LinkedIn post, and
customer apology.

## Contents

- `prompts/` — the system prompt template
- `tests/` — input/output pairs for each content type
